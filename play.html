Play — Game Design

At UC Davis I spent a few quarters learning how to design and build digital game experiences. This is a collection of those games — each one exploring a different medium and idea.

Unity Twine HTML CSS JS

01

Frog Cat ↗

CDM 175 · Digital Game Design

A two-week piece of interactive fiction built in Twine, drawn from children’s books like If You Give a Mouse a Cookie. You guide a little black cat on his journey to make new friends.

Twine
play fruitninja
02

Cloudy with a Chance of Fruit Ninja ↗

CDM 175 · Digital Game Design

An abstract arcade game: collect 100 fruits, think you can do it? I focused on the UI and on scripting the randomisation of falling fruit and hazards, aiming for progress that reads clearly and gameplay that feels juicy.

Unity
play escape
03

Escape from School ↗

CDM 175 · Digital Game Design

The final course project, made with two others. I built the sprite sheets, developed each scene, drew and animated the main character, and wrote the script — the story of a boy trapped in a school bathroom looking for a way out.

Unity

Battle of the… Birds? ↗

DES 157A · Interactive Media II

A deeper dive into front-end UI and JavaScript: the Pig Game evolved into a strategic 1v1 fighter with the same turn-taking mechanic, plus your own adorable bird mascot to pick.

HTML CSS JS

25 Days as a College Student ↗

DES 157B · Interactive Media III

A semester-long capstone on the theme “Designing Your Future.” I chose education — a sim-like project that puts players through tough choices, each leading somewhere different.

HTML CSS JS

What Kind of Cleaning Supply are You? ↗

DES 157B · Interactive Media III

Not quite a game — a personality quiz built to stretch UI and coding skills and to explore JavaScript libraries. Take it and find out which cleaning supply matches your personality.

Museum ↗

A simple, immersive simulation of a Greek museum with an interactive piano, made as the final project for a VR special-topics course. Requires an Oculus VR headset — the link downloads a ZIP of the game and a readme with contact details.
